## Changes and decisions

Dave's September 16 decisions (DAVE.md): drop the ESV API, keep the Scripture text already written in lesson verse blocks, use the World English Bible for the John reading cards, leave the root `dailybiblereading/` app alone, and delete its copy inside `discipleship/`. No lesson JSON changed.

The only API use in the discipleship app was the 101 weekly reading cards (John 1 through 21). `data/bible/john-web.json` now holds the WEB text of John, built from eBible.org's public domain `eng-web_usfm.zip` (`73-JHNeng-web.usfm`) by `scripts/build_john_web.js`. Footnotes and cross references are omitted; the wording is unchanged. The card loads that file once per page, renders verses as escaped text with the existing verse number styling, marks poetry lines, and shows "World English Bible (WEB), public domain" under the chapter. ESV audio came from the API, so the hidden audio player was removed. The page footnote keeps the ESV notice for lesson quotations and adds the WEB note for the John readings. The credential line in PROJECT-BRIEF.md was replaced with a description of the bundled text.

Saved reading checkboxes and notes use the same IDs as before (`reading-check-101-John-N`, `notes-101-John-N`), so existing learner data is unaffected.
