## Done
- **Web app registered:** "Growing Together Web" (`1:1081223639793:web:1b336388cab43d9067af50`) in project `growing-together-discipleship`, so the site has a Firebase web config. The config is public by design; see the DATA-002a log.
- **`scripts/account-helpers.js`:** decides where sign-in runs and words the error messages. Sign-in runs only on growingtogetherdiscipleship.com, www, and the project's own web.app and firebaseapp.com addresses (including preview links). On localhost it runs only with `?auth=emulator`. A wrong password and an unknown email get the same message, so the page never says whether an email has an account.
- **`scripts/account.js`:** a module that loads Firebase Authentication 13.1.0 from gstatic only where sign-in runs. It supports Google (pop-up window), email and password sign-in, creating an account (6-character minimum, Firebase's default), Forgot password (reset email), and sign-out. People stay signed in after reload.
- **`index.html`:**
  - The home screen has a Sign in button below Browse All Courses and Lessons. Under it is the line "For now, your answers still save on this device only."
  - When someone is signed in, the home screen shows "Signed in as (email)" and a Sign out button.
  - The sign-in dialog reuses the Email Lesson dialog's look. It has "Continue with Google", email and password, Forgot password?, and a "New here? Create an account" switch.
  - The dialog has a focus trap, Escape closes it, and focus goes back to where it was.
- **`firebase.json`:** an `emulators` block for the Authentication emulator on 127.0.0.1:9099.
