## Why the Firebase web key can be public
The web config Firebase gives for a site (`apiKey`, `authDomain`, `projectId` and so on) only tells Google which project the app belongs to. Google's documentation says it is meant to be included in public web code. It does not grant access by itself. What protects people's answers is:
1. **Firestore security rules (DATA-002c).** Each signed-in person can reach only their own data. Until then, the rules deny everything.
2. **Authorized domains in Authentication.** Sign-in only works from growingtogetherdiscipleship.com, ministrybag.com and the Firebase preview addresses.

This differs from the old ESV key (SEC-001), which was a service credential.
