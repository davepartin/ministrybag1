# Denomination Comparison Guide

An interactive guide for comparing commonly encountered U.S. Christian traditions across doctrine, sacraments, governance, ministry, ethics, and eschatology.

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` and `npm run lint` before publishing.

## Editorial approach

Placements summarize official catechisms, confessions, denominational statements, and policy pages. The five-point spectra are descriptive, not evaluative. They are intentionally presented as a starting point, with source links and variation notices where no single central authority exists.

This project uses React, TypeScript, Vite, and Tailwind CSS.
